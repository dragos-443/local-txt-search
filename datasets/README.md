# Dataset

I corpus preparati nella milestone M1 sono versionati insieme al progetto:

- `synthetic/`: 12 documenti UTF-8 controllati e una fixture non UTF-8;
- `real/`: 200 introduzioni di voci Wikipedia, 100 italiane e 100 inglesi,
  con revisioni, attribuzione, dimensioni e hash registrati nel manifest.
  I 50 file iniziali sono identificati da `real/initial_50.json`.

Le licenze e le procedure di riproduzione sono documentate nei README delle
due directory. Gli indici Whoosh generati da questi file non sono versionati.
